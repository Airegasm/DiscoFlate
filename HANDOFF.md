## The action system is now consolidated
One editor, one action list everywhere (commands `actions` type, timed events `actions` type, capacity events, competition `win_actions`/`no_winner_actions`, bonus round `actions`, poll options, minigame tiers, chance win/miss, nested button/post-pump blocks).

**Action types:** `message` · `broadcast` · `command` · `fire` · `roll` · `capacity` · `wait` · `poll` · `competition` · `bonus_round` · `award` · `command_gate` · `end_session`.
- **`message`**: `style` = plain|embed (+ `title` for embed) + OPTIONAL gated button — `target` = ""(none)/winner/runnerup/range_leader/session_leader/top_bonus_holder/everyone/allowlist(+`allow[]`) + `label`+`freeze`+`deadline`+`deadline_message`+`timeout_message`+nested `actions`. (Absorbed the old `embed_message`/`winner_button`/`session_leader_event`.)
- **`award`**: `award_type` = command|secs|pct. command → `command`+`charges`+`stash`+`lock`+`deadline`(+msgs); secs/pct → `amount` (banked for a Bonus Round). (Absorbed `award_prize`/`award_amount`.)
- **`fire`**: `fire_mode` = seconds|add|to (+ `fill_pct`), `seconds` accepts a number OR `[placeholder]`, `block_during`, nested `post_actions`.
- **`command_gate`**: `modifiers[]` = `{op, command?}`. ops: block_all / remove_block / allow / unallow / block / unblock / disable_range_cmds / resume_range_cmds / disable_always_on / resume_always_on / pause_events / resume_events. `allow` is a UNIVERSAL bypass (feeds `_capev_enabled_cmds`). Reuses `_capev_session_fx` for the disable/pause effects. Legacy `gate_mode` still read.

**Migrations (config_store.py `_migrate`):** v4 legacy comp awards→win_actions · v5 race/raffle→rolloff · v6 embed_message/winner_button/session_leader_event→`embed` · v7 chance fires→win/miss actions · v8 award_prize/award_amount→`award`, `embed`→`message` · v9 capev gating tickboxes→`command_gate` rows in the block (event-scope = disable-at-start + resume-at-end; session-scope persists; enable_commands→allow+unallow). All are recursive/idempotent.
