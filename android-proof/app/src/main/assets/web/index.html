Devices

The active device (radio) is what !roll fires. Calibrate = time how long the pump runs to fill to 100% (tap Calibrate → wait until full → tap Full; the elapsed seconds become secs→100%). Kasa is local (no account); other brands need their credentials above. Only Kasa is verified — the rest are ported from PumpDirect and unconfirmed.

Capacity ranges

Announce shows with roll/capacity while in the range · Milestone/Image post once on reaching it. ⚙ Per-command settings sets each command's dice (roll), enabled toggle, cooldown & scope, a Range Start Command, and event actions on entry.
🏁 End Sequence = a range with a final threshold; reaching it posts a final message then ends & resets the session (no activation-off message). End = just that terminal threshold, no buildup. Capacity may tick above 100% up to the End threshold. Only one End / End Sequence is allowed, and nothing comes after it.

System commands

Only the dice roll can be turned off. Help (DMs the command list) & Leaderboard (top pumpers) output isn't editable. The anti-spam buffer quietly ignores back-to-back uses of the same command within that many seconds (0 = off).
A perfect roll counts toward a prize. Gate each to a range or All (All overrides ranged). Perfect counts carry forward; unlocked prizes persist until used up or Session reset.

Custom commands

fire = active device on for fixed seconds. roll = roll dice (blank dice/sides uses the current capacity range) and fire for the total. say = text-only reply, no device. See the Help tab for reply placeholders. Starts events = names of (off-by-default) events this command switches on temporarily (they revert on Session reset or app restart).

Modes

A mode's switch enables/disables all its commands and events at once. Fill On/Off messages to announce the change in the announce channel, or leave them blank to toggle quietly. Save a mode before its switch goes live.

Timed events

Events are OFF by default — tick one to run, or have a custom command start it temporarily. loop fires every N seconds; once fires a single time N seconds after Activation turns on (re-arms off→on). Runs only while Activation is on; turning Activation off cancels all events and clears cooldowns.
message = post to announce channel · fire = run a device for N secs · roll = auto-roll a device · capacity = add/set % (op + value). Every action can also post its message. Placeholders work everywhere.

Set up your private Discord bot

A 2-minute, one-time setup. There's no verification or app review — that only applies to bots in 100+ servers. Each person runs their own bot with their own token; never share a token.
  1. Open the Discord Developer Portal → New Application → give it a name (e.g. your bot's name) → Create.
  2. Left sidebar → Bot. Under Privileged Gateway Intents, turn Message Content Intent ON (required so it can read commands) and Save.
  3. Still on the Bot page, turn Public Bot OFF — now only you can invite it. This is what makes it a private bot.
  4. Left sidebar → Installation. Set Install Link to None — this removes the public add-to-server link, keeping the bot fully private.
  5. Get the token: on that same Bot page, in the Token section click Reset Token (Discord keeps the token hidden, so this reveals a fresh one) → Copy it immediately — it's only shown once. Keep it secret; it's your bot's password. You'll paste it in step 6. (Lost it? Just Reset Token again — that makes a new one.)
  6. Left sidebar → OAuth2 → URL Generator. Tick scope bot; under permissions tick Send Messages (and Attach Files if you'll use images/snapshots). Copy the generated URL at the bottom, open it, and add the bot to your server.
  7. Back here → Discord tab → paste the token → Save & connect → pick the server and channel to listen on.
  8. Flip Activation on (top-right) and test from the Dashboard → Controls.
If it connects but doesn't respond to commands, re-check that Message Content Intent is on (step 2) and that you picked the right channel (step 6).

Adding your bot to someone else's server

Because it's private, only you can add it — you can't hand a friend a link. Two ways to get it into a server you don't own:
  • Stay private (cleanest): have that server's owner give you the Manage Server permission there, then open your own invite link (step 6) and pick their server — as the app owner it works even while private. Remove the permission afterward if you like.
  • Temporarily go public: Portal → Bot → turn Public Bot ON, and Installation → set Install Link to Discord Provided Link. Now anyone with Manage Server there can add it with the link. Once it's in, switch Public Bot back OFF and Install Link back to None to re-lock it.
Either way it's harmless to be in another server — your bot only fires your devices and only listens in the channel you select; elsewhere it just sits idle.

Placeholders & examples

Message placeholders

Any of these can go in any message field; they're filled in when the bot posts.
[user]the person's name (plain text)
[mention]@pings the person (a real Discord mention)
[operator]the bot operator's name
[capacity]current capacity %, e.g. 47.5
[capacity_bar]emoji bar 🟩🟩🟩⬛⬛
[timer] / [total_secs]seconds left on the active pump
[announce]the current range's Announce text
[commands]all commands usable right now — Capacity Range Commands (this range's customs) on top, System Commands below
[custom_commands]just the Capacity Range Commands (start%–stop%) header + this range's custom commands (no system commands)
[prefix] [roll_cmd] [capacity_cmd] [stop_cmd]the command names (e.g. !agroll)
[max_roll_goal] [max_roll_command] [max_roll_desc]the active prize's goal / command / description

Roll / command replies only

[dice]dice notation, e.g. 2d6
[result]the roll total
[secs]seconds this fire runs
[secs2capacity]% capacity this fire will add
[sides]number of sides
[cmd_remain]this person's uses left for the command — the word “unlimited” when the command has no per-person limit (blank Max/person)

Cooldown / prize replies

[cooldown]seconds left on cooldown
[count] [goal] [remaining]prize progress numbers
[prize_cmd] [prize_desc] [uses] [uses_left]prize command details
